# 2gal

Приложение для Android: **сохраняет видео в галерею через «Поделиться»** —
рилсы, фото и карусели из Instagram по ссылке и видео из Telegram.

**[Скачать последнюю версию →](../../releases/latest)**

---

## Что делает

| Откуда | Что приходит | Что происходит |
|---|---|---|
| **Instagram** | ссылка на рилс или пост | 2gal скачивает видео или фото в лучшем доступном качестве |
| **Telegram** и другие приложения | видеофайл | 2gal копирует его без перекодирования |

- В Instagram или Telegram нажмите **«Поделиться» → 2gal**. Экран не открывается:
  ход сохранения и результат видны в уведомлениях, нажатие на «Сохранено» открывает файл.
- **Карусель:** приходит уведомление с выбором — сохранить первый элемент или все.
- **Повторы не сохраняются:** тот же рилс второй раз не скачивается. Если файл удалён
  из галереи, он скачается заново.
- Всё складывается в альбом **«2gal»**: видео — `Movies/2gal/`, фото — `Pictures/2gal/`.

## Вход в Instagram

Без входа доступны только публичные посты. Чтобы сохранять из закрытых аккаунтов,
на которые вы подписаны, войдите в Instagram на главном экране 2gal.

- Логин и пароль вводятся **на странице Instagram**, приложение их не видит и не хранит.
  Сохраняется только сессия; кнопка «Выйти» её удаляет.
- **Instagram может ограничить или заблокировать аккаунт** за автоматические запросы.
- Скачивание из Instagram не поддерживается официально и может перестать работать после
  изменений на стороне Instagram. Исправления выходят новыми версиями.

## Требования

- **Android 10 (API 29) и новее.** Проверяется на Xiaomi 17 (HyperOS 3, Android 16).
- На Xiaomi включите для 2gal «Автозапуск» и «Без ограничений» в контроле активности —
  на главном экране есть кнопки, ведущие в эти настройки.

## Установка

Приложение распространяется сайдлоадом, без Google Play.

1. Откройте **[последний релиз](../../releases/latest)** и скачайте `2gal-<версия>.apk`.
2. Разрешите установку из неизвестных источников для браузера или файлового менеджера.
3. Установите APK.
4. При желании сверьте контрольную сумму — `SHA256SUMS` лежит в том же релизе:

   ```bash
   shasum -a 256 -c SHA256SUMS
   ```

## Обновления

Приложение обновляется само: проверяет новую версию при открытии главного экрана и по кнопке
**«Проверить обновление»**, показывает размер файла, скачивает APK с прогрессом и передаёт
установку системе.

- **Файл проверяется трижды** до установки: контрольная сумма SHA-256, имя пакета и номер
  версии внутри файла, подпись — она должна совпадать с подписью установленного приложения.
- **Установку подтверждаете вы** в системном диалоге; тихой установки нет.
- **После установки приложение закроется** — запустите его заново.
- Пока идёт сохранение медиа, обновление не устанавливается.

## Приватность

Телеметрии, аналитики, рекламы и crash-репортинга нет. Приложение обращается только к:

- **Instagram** — за файлом по присланной вами ссылке;
- **GitHub** (`api.github.com`, `github.com`) — за проверкой обновлений, только по HTTPS.
  Проверку при открытии можно выключить.

**Сессия Instagram, ссылки и имена файлов никогда не попадают в запросы к GitHub.**
Из сведений об устройстве передаётся только версия приложения в заголовке `User-Agent`.
